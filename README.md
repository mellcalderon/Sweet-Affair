# Pagina Web  Sweet-Affair

Este proyecto es desarrollado para el emprendimiento Sweet Affair, dedicado a la elaboración y venta de postres. Con el fin de satisfacer los antojos de nuestros clientes, ofrecer productos de calidad y crear experiencias dulces a través de postres deliciosos y presentaciones atractivas, en el mercado de repostería.

Todo el contenido pertenece a Melisa Calderon; en caso de utilizarlo, se debe citar al autor.
